# Actividad 1: Identificación y Evaluación Cuantitativa de Riesgos

Este directorio contiene el análisis de amenazas y vulnerabilidades para el sistema distribuido de LogiMarket Perú.

## Contenido

- **`matriz_riesgos.md`**: El documento principal del análisis, estructurado con una metodología cuantitativa de Probabilidad x Impacto (P x I), asociando cada uno de los 5 incidentes críticos del caso y proponiendo los mecanismos de control correspondientes.
